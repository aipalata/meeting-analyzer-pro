# AI-анализатор встреч — PRO и PRO+

Работающее приложение: https://meeting-analyzer-pro-gamma.vercel.app/


PRO развивает Lite: загрузите MP4/WebM с компьютера или вставьте ссылку на файл Google Drive с открытым скачиванием. На панели показываются источник, дата и реальный этап: получение файла, распознавание, AI-анализ, готово или ошибка. Обе загрузки используют одну обработку FFmpeg и OpenAI. Готовый конспект и расшифровка сохраняются в IndexedDB этого браузера. Повторная ссылка на тот же файл Google Drive открывает сохранённый результат; если файл заменили по тому же идентификатору, повторная обработка по ссылке не определяется — используйте ручную загрузку.

Для Google Drive включите доступ «Все, у кого есть ссылка» и разрешите скачивание. Если ссылка недоступна или Google возвращает страницу подтверждения, скачайте файл самостоятельно и загрузите через кнопку «Загрузить видео». Размер видео — до 200 МБ. Не закрывайте страницу во время обработки: задачи не продолжаются в фоне после её закрытия. Используйте запись с согласия участников.

Локальный запуск: Node.js 22+, `npm install`, настройка приватного Vercel Blob (`npx vercel link`, `npx vercel env pull .env.local`), затем `npm run dev`. Введите свой API-ключ OpenAI в интерфейсе. Требуются доступ к моделям и баланс API. При обычной загрузке ключ хранится только в памяти страницы; при настройке PRO+ он сохраняется на сервере в зашифрованном виде для фоновой обработки. Данные встречи сохраняются в текущем браузере, исходное видео временно хранится в приватном Blob и удаляется после обработки, при прерывании — по TTL не ранее суток.

Проверки: `npm run check`, `npm test`, `npm run build`. Исходная Lite-версия сохранена отдельно.

## PRO+ и Яндекс Диск

Подключите Яндекс Диск через кнопку в приложении и разрешите чтение. Яндекс выдаёт разрешение на чтение всего Диска; приложение проверяет только указанный путь. Введите ключ OpenAI и путь, например `disk:/Встречи`, затем нажмите «Сохранить и проверить». Ключ и токены хранятся на сервере в зашифрованном виде; результаты доступны в браузере, где выполнено подключение. Проверка по расписанию настроена один раз в сутки и обрабатывает не более одной записи за запуск; дополнительную проверку можно запустить кнопкой. Свежие файлы обрабатываются не ранее чем через две минуты после изменения.

Для удаления серверных настроек и результатов нажмите «Отключить Диск» до очистки данных браузера. При необходимости отзовите разрешение в Яндекс ID. Очистка браузера сама по себе не отключает серверную проверку.

Серверные настройки: `PRO_PLUS_ORIGIN`, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `PRO_PLUS_ENCRYPTION_KEY` (32 случайных байта в hex), `CRON_SECRET` и приватное хранилище Vercel Blob. Не менять ключ шифрования после подключения: это сделает ранее сохранённые данные недоступными. В планировщике Vercel установлен ежедневный запуск. Локальные файлы секретов не публиковать.

Проверено на опубликованном приложении: реальная запись обработана из Google Drive и Яндекс Диска, готовый конспект Яндекс Диска сохранился после обновления страницы. Планировщик зарегистрирован в Vercel; его самостоятельный запуск по расписанию пока не наблюдался.
